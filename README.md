# FlaxGlow

A responsive React landing page for a flaxseed hair-care student prototype, featuring a Three.js product scene and GSAP scroll animation.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The product section lists a prototype price of ₹69 per bottle and includes a demo cart. Checkout, payment, and delivery are not connected. The formulation's effectiveness, scalp safety, and shelf life have not been validated.
